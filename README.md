# منصة رياضيات البكالوريا السورية

## محتويات النسخة المطوّرة
- 14 محوراً تدريبياً، بينها محاور الأشعة الثلاثة بصورة منفصلة.
- 56 سؤالاً تدريبياً نموذجياً (4 أسئلة لكل محور)، وكل سؤال له أربعة خيارات وإجابة صحيحة وحل مشروح.
- تصحيح فوري بعد اختيار الإجابة مع تمييز الخيار الصحيح والخيار المختار الخاطئ.
- شريط تقدّم ونتيجة نهائية ونسبة مئوية.
- مراجعة الأسئلة التي أجاب عنها الطالب إجابة خاطئة مع الحل.
- اختبار شامل يخلط أسئلة جميع المحاور.
- البحث عن المحاور، وتصميم متجاوب مع الهاتف والكمبيوتر، ودعم عرض المعادلات عبر MathJax.

## الملفات
- `index.html`: هيكل الصفحة.
- `style.css`: الألوان والتنسيق والتجاوب.
- `app.js`: منطق الاختبارات والتصحيح والنتائج.
- `questions.js`: أسماء المحاور والأسئلة والخيارات والإجابات والحلول.

#### ملاحظة مهمة حول المنهاج
الأسئلة الحالية تدريبية نموذجية وليست بنكاً رسمياً شاملاً أو معتمداً من وزارة التربية. تم فصل الأشعة إلى ثلاثة محاور تدريبية: الأشعة في المستوي، والأشعة في الفراغ، والمستقيمات والمستويات في الفراغ. ينبغي مراجعة الأسئلة والحلول ومطابقتها مع الطبعة المعتمدة من كتاب الرياضيات السوري قبل اعتمادها للتحضير الامتحاني النهائي.
