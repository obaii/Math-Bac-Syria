# منصة رياضيات البكالوريا السورية

نسخة مطوّرة من منصة تدريب عربية بسيطة لطلاب البكالوريا العلمي، قابلة للنشر مجاناً على GitHub Pages ولا تحتاج إلى خادم أو قاعدة بيانات.

## محتويات النسخة المطوّرة
- 14 محوراً تدريبياً، بينها محاور الأشعة الثلاثة بصورة منفصلة.
- 56 سؤالاً تدريبياً نموذجياً (4 أسئلة لكل محور)، وكل سؤال له أربعة خيارات وإجابة صحيحة وحل مشروح.
- تصحيح فوري بعد اختيار الإجابة مع تمييز الخيار الصحيح والخيار المختار الخاطئ.
- شريط تقدّم ونتيجة نهائية ونسبة مئوية.
- مراجعة الأسئلة التي أجاب عنها الطالب إجابة خاطئة مع الحل.
- اختبار شامل يخلط أسئلة جميع المحاور.
- البحث عن المحاور، وتصميم متجاوب مع الهاتف والكمبيوتر، ودعم عرض المعادلات عبر MathJax.

## الملفات
- `index.html`: هيكل الصفحة.
- `style.css`: الألوان والتنسيق والتجاوب.
- `app.js`: منطق الاختبارات والتصحيح والنتائج.
- `questions.js`: أسماء المحاور والأسئلة والخيارات والإجابات والحلول.

## التشغيل محلياً
فك ضغط الملف ثم افتح `index.html` في المتصفح. يلزم اتصال بالإنترنت لتحميل MathJax والخط المستخدم؛ أما بنية الاختبار نفسها فتعمل محلياً.

## النشر على GitHub Pages
1. سجّل الدخول إلى GitHub وأنشئ مستودعاً جديداً عاماً (Public)، مثلاً `syrian-baccalaureate-math`.
2. ارفع الملفات الأربعة `index.html` و`style.css` و`app.js` و`questions.js` إلى جذر المستودع.
3. افتح `Settings` ثم `Pages`.
4. ضمن `Build and deployment` اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط `Save`.
6. بعد اكتمال النشر سيظهر رابط الصفحة ضمن إعدادات Pages، ويكون عادةً بالشكل `https://اسم-المستخدم.github.io/syrian-baccalaureate-math/`.

## إضافة سؤال أو تعديله
افتح `questions.js`. يحتوي كل سؤال على:
- `topic`: اسم المحور، ويجب أن يطابق أحد العناصر في مصفوفة `topics`.
- `q`: نص السؤال، ويمكن كتابة المعادلات بصيغة LaTeX بين `\(` و`\)`.
- `options`: أربعة خيارات بالضبط.
- `answer`: فهرس الخيار الصحيح بدءاً من الصفر (0 للأول، 1 للثاني، 2 للثالث، 3 للرابع).
- `solution`: خطوات الحل أو تفسير الإجابة.

## ملاحظة مهمة حول المنهاج
الأسئلة الحالية تدريبية نموذجية وليست بنكاً رسمياً شاملاً أو معتمداً من وزارة التربية. تم فصل الأشعة إلى ثلاثة محاور تدريبية: الأشعة في المستوي، والأشعة في الفراغ، والمستقيمات والمستويات في الفراغ. ينبغي مراجعة الأسئلة والحلول ومطابقتها مع الطبعة المعتمدة من كتاب الرياضيات السوري قبل اعتمادها للتحضير الامتحاني النهائي.
