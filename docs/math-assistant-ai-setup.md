# تفعيل الشرح الذكي للمساعد الرياضي

تستخدم هذه النسخة Cloudflare Workers AI مع النموذج `@cf/meta/llama-3.2-3b-instruct`. تبقى المنصة الأساسية على GitHub Pages، بينما يعمل هذا الملف كخدمة مستقلة للشرح الذكي.

## قبل النشر

- يلزم حساب Cloudflare مخوّل لإدارة Worker وربط Workers AI.
- لا تضع أي مفتاح أو رمز سري في ملفات الموقع أو GitHub.
- لا ترسل أسماء الطلاب أو بريدهم أو أرقامهم أو أي بيانات شخصية إلى المساعد.
- الحصة المجانية الحالية لـ Workers AI هي 10,000 Neurons يومياً على خطة Workers Free. عند استهلاك الحصة تتوقف طلبات AI حتى إعادة ضبطها، ولا يلزم الترقية إلى خطة مدفوعة لتشغيل الموقع الأساسي.

## نشر الخدمة

من مجلد المشروع، بعد إعداد Node.js:

1. سجّل الدخول إلى Cloudflare من الطرفية:
   `npx wrangler login`
2. انشر الخدمة:
   `npx wrangler deploy --config worker/wrangler.toml`
3. سيعرض Wrangler عنواناً ينتهي عادةً بـ `.workers.dev`.
4. افتح العنوان مع المسار `/health`. يجب أن تحصل على استجابة JSON فيها `"ok": true`.

الملف `worker/wrangler.toml` يعرّف ربط AI باسم `AI`، لذلك لا تحتاج إلى إضافة مفتاح API للنموذج.

## ربط الموقع بالخدمة

افتح `math-assistant-config.js` وضع عنوان Worker العام فقط في المتغير:

`window.MATH_ASSISTANT_API_URL = "https://YOUR-WORKER.workers.dev";`

استبدل القيمة بعنوان Worker الحقيقي، من دون إضافة `/api/ask` إلى نهايته. هذا العنوان ليس سراً؛ لا تضع فيه مفاتيح أو رموز وصول. احفظ التعديل في GitHub، ثم ستصبح ميزة «اشرح لي الحل بالتفصيل» متاحة بعد نشر الموقع.

## الحماية والحدود

- الخدمة تقبل الطلبات من نطاق GitHub Pages المحدد في `worker/index.mjs` ومن localhost للاختبار.
- يوجد حد أولي لحجم السؤال والسياق، وحد للطلبات في الدقيقة لكل عنوان IP ضمن نسخة Worker الواحدة. هذا الحد الأخير احترازي وليس نظام مصادقة أو حماية موزعة كاملة.
- حصة Workers AI المجانية اليومية هي الحد الأعلى للاستهلاك على الخطة المجانية؛ إذا استُهلكت، يبقى البحث المحلي في القوانين والأمثلة متاحاً.
- إجابات النموذج قد تخطئ؛ ينبغي مراجعة خطوات الحل والتحقق من النتائج، خصوصاً في المسائل الامتحانية.

## الاختبارات

يشغّل مسار GitHub Actions اختبار الواجهة واختبار Worker محلياً باستخدام نموذج وهمي. لا يستدعي الاختبار النموذج الفعلي ولا يستهلك حصة AI.
